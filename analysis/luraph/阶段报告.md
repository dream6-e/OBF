## 1. 外壳结构总览

```
({ 178 个顶层字段的巨型匿名表 }):T()(...)
```
- 整个脚本是**单个表构造 + 自调用**，无任何顶层语句泄漏语义。
- 字段即代码：177 个非函数字段里只有字符集/短值（op/str/name/num/keyword 各少量），其余全部为**函数字段**，内部全部是相同的模式：
  `for k = a, b, s do if k==c1 ... elseif k==c2 ... end` 或 `repeat ... T = R:XX(...) until false` 的**手工状态机**（多入口 for 循环伪装有向图）。
- `T`（入口字段，索引 54）按序驱动 14 个阶段：`M → Q → u → G → f → v → q → j → BU → WU → AU → _G → nG`，最后 `JS` 收尾并返回。
- 全部状态跳转常量经由**槽位间接层**计算：`T[NNNN]`/`x[NNNN]` 槽里存"下一次该走的数"，表达式 `R.YS(R.FS(R.SS(....)...))` 配合 `R.w[1..9]` 九颗种子走 bit32 混合（左右移/异或/循环/三一律 `a<b and x or y`），静态可求值但刻意不可读。

## 2. 突破点一：自定义转义方言与 tokenizer

- 文件是 Lua 5.1 的超集变体：`//`（整除）、`0b1001011_0010101_...`（带下划线的二进制字面量）、`-> : =`、`local ... = ...` 正常、`for k = a,b,s do`。
- **字符串转义是非标的**：存在 `\i \z \s \r \x \J \V \d` 等"保留原形"的恒等转义（Lua 标准里没有 `\i` 之类）——这是 LurAPH 用来打断现成解析器的第一道小墙。
- 自制 `work/luraph/tok.py`：手写 Luau 方言 tokenizer（处理恒等转义、`[==[` 多级长字符串、数字下划线）。错误分支处曾经把 blob 长字符串切碎，修正为多级长字符串匹配后得到 **42,104 个 token**。
- 字段切分器：以顶层逗号为界，但必须跟踪 `function/if/for/while/do/repeat/end/until` 关键字栈，否则函数字段体内的逗号会造成假切分（早期沟里学到的）。

## 3. 突破点二：payload 层（第 1 层容器）完全破解（✅ 已自证）

字段 `y[38]`（位于 `BU` 阶段，token 34695–35080）verbatim 摘出：

```lua
x = #O - 4                                    -- 跳过 4 字节头 "LPH@"
f = buffer.create( (x) // 5 * 4 )             -- Ascii85: 5 字符 → 4 字节
O = gsub(O, "z", "!!!!!")                     -- 压缩回填：'z' 展成 "!!!!!"
for i = 0, a/5 - 1 do
  b1..b5 = O:byte(i*5+1 .. i*5+5)
  P = (b5-33) + (b4-33)*85 + (b3-33)*7225 + (b2-33)*614125 + (b1-33)*52200625
  writeu32(f, a, P)  -- 小端 u32；a += 4
end
```
- 数学核验：`52200625 = 85^4`，`614125 = 85^3` —— 大端 Ascii85 组 `(_,_,_,_,_) → u32`，末组照常 5→4（无对齐填充分支，故总长必须 `(len-4) % 5 == 0` ✓ 实测成立）。
- `z→"!!!!!"` 展开后 **175,814 = 174,858 + 956×1**（共 956 个 `z`）。
- Python 复刻解码得 **`work/luraph/stage1.bin`，140,648 字节**，头部 u32 = `0x0003EC85 = 257157`（字段语义未明，不是 crc32/adler32/u8/u16/u32 简单校验——已过一轮快速预言机尝试，排除法记录）。
- 头部后跟 ~57 组 `1e XX` 对规则字节模式、熵 5.61 bits/byte —— 结构化容器（非随机填充），自证解码正确。
- 模式分支：`y[37]=236`（正常路径）；`y[37]==2/25/177`、`y[10]==2^31`、`j[10]==209·j[10]` 是**永不命中的诱饵分支**（T 驱动器固定写入 236 / 非 2³¹。
